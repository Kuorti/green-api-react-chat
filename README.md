# GREEN-API Chat App

Простое клиентское приложение для обмена текстовыми сообщениями через систему **GREEN-API** с использованием WhatsApp. Разработано в качестве тестового задания.

🚀 **[Живое демо на GitHub Pages](https://github.com/Kuorti/green-api-react-chat)**

---

## 🛠 Технологический стек

* **Frontend:** React 18, TypeScript, Vite
* **UI-компоненты:** `@chatscope/chat-ui-kit-react` (интерфейс чата), `react-bootstrap` (экраны авторизации)
* **Иконки:** `FontAwesome`
* **Стейт-менеджмент:** `Zustand` (для хранения данных сессии `idInstance` / `apiTokenInstance`)
* **API Интеграция:** HTTP API GREEN-API (методы `sendMessage`, `receiveNotification`, `deleteNotification`)

---

## 💡 Реализованный функционал

1. **Экран авторизации:** Форма ввода учетных данных инстанса (`idInstance` и `apiTokenInstance`). Данные сохраняются в глобальный стейт-менеджер.
2. **Создание чата:** Экран ввода номера телефона получателя (в международном формате) для открытия прямой сессии переписки.
3. **Отправка сообщений:** Мгновенное отображение исходящего сообщения в интерфейсе и его отправка на реальный номер WhatsApp через эндпоинт `sendMessage`.
4. **Получение ответов (Long Polling):** Вынесенный кастомный хук `useLongPolling`, который циклически опрашивает очередь уведомлений методом `receiveNotification`, фильтрует сообщения по текущему открытому чату и удаляет обработанные элементы через `deleteNotification`. Цикл оптимизирован (запросы не накладываются друг на друга при ожидании сервера).
